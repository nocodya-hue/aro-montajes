# Montajes y Reparaciones ARO · web de muestra

Propuesta de web para **Montajes y Reparaciones ARO S.L.**, taller de reparación y mantenimiento de maquinaria en Enguera (Valencia). Diseño y desarrollo: NOCODYA.

**Ver online:** https://nocodya-hue.github.io/aro-montajes/

## Qué incluye
- Portada con un carrusel por capas que cambia de escena con el scroll, el taller por dentro con zonas y zoom, los pasos de trabajo, la flota y un contacto con el símbolo de la marca en 3D.
- 5 páginas de servicio con SEO local: datos estructurados, sitemap y robots.
- Logo redibujado a partir del suyo: «ARO» con el engranaje y la llave como «O».

## Antes de publicarla de verdad
- Las imágenes del carrusel y de algunos servicios son **ilustrativas, generadas con IA**. Las fotos del taller, la nave y la flota son reales, de su ficha de Google.
- Falta que el cliente confirme:
  - el WhatsApp;
  - la lista de servicios y sus textos;
  - que la carpintería es metálica;
  - el servicio en las instalaciones del cliente;
  - el domicilio;
  - el dominio.
